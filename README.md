# Predicción del Rendimiento Académico con Machine Learning

## Descripción
Proyecto enfocado en el análisis comparativo de modelos de Machine Learning para la predicción del rendimiento académico utilizando el dataset OULAD.

## Dataset
OULAD (Open University Learning Analytics Dataset)

## Objetivo
Identificar estudiantes en riesgo académico mediante técnicas de ML y análisis de datos.

## Tecnologías
- Python
- Pandas
- Matplotlib
- Scikit-learn
